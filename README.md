# pokecoach2-trainer

Trainer BC Tiny (palier 1) pour PokeCoach — Devbox + uv, API FastAPI locale, CLI.

## Démarrage

```bash
devbox run setup
devbox run check
devbox run test
devbox run start
```

Diagnostic et checkpoint de référence :

```bash
devbox run cli -- doctor --reference-checkpoint /chemin/vers/100.zip
```

Interpréteur IDE : `pokecoach-trainer/.venv/bin/python`

Plan détaillé : `docs/plans/2026-11-02-palier-1-trainer-bc-tiny.md`
